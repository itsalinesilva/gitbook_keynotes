# IA Para Analise de Dados



​- Digamos que você esteja explorando maneiras de ​melhorar os serviços da sua empresa. ​Assim, você coleta alguns dados de pesquisas ​, obtém relatórios sobre retenção de clientes ​e coleta notas de reuniões de seus colegas. ​Antes que você perceba, eles têm muito com que trabalhar. ​Mas agora, você tem um tipo diferente de desafio. ​Com todas essas fontes diferentes, ​como você entende tudo isso? ​Nem todo mundo tem treinamento sobre como analisar dados ​e, mesmo para aqueles que o fazem, ​nem sempre é fácil obter informações claras dos dados brutos. ​Mas a análise de dados pode ser uma ferramenta incrivelmente valiosa.

\
​Por quê? ​Porque os dados podem ajudar você a tomar as melhores ​e mais informadas decisões, ​além de fornecer suporte ​para seu ponto de vista sobre qualquer problema. ​Agora, com a IA, ​até mesmo pessoas cujos olhos normalmente olhariam para ​o site de uma planilha ​podem aproveitar o poder dos insights de dados. ​Gêmeos pode pegar dados confusos e dizer o que tudo isso significa. ​Ele pode até mesmo dar sentido a ​diferentes tipos de dados ao mesmo tempo, ​como números de retenção de clientes e feedback de pesquisas. A ​IA pode fazer com que as ​partes mais frustrantes e demoradas da análise de dados ​simplesmente desapareçam em segundo plano. ​Você pode até mesmo criar visualizações ​para comunicar suas descobertas.

\
​Você também pode fazer análises mais complexas de novas maneiras ​usando a linguagem cotidiana com o Gemini in Sheets, além de ​acelerar a limpeza de dados ​e descobrir padrões entre diferentes fontes de dados. ​Ele até solucionará problemas de fórmulas complicadas para você. ​Tudo isso significa que você pode descobrir informações valiosas ​em uma fração do tempo que normalmente levaria. ​Agora, você pode estar pensando ​: “Se Gêmeos pode fazer toda essa análise para mim, ​o que eu tenho que fazer?”

<figure><img src=".gitbook/assets/image (89).png" alt=""><figcaption></figcaption></figure>

&#x20;​Bem, primeiro você ainda precisa fazer ​perguntas muito boas sobre os dados. ​Às vezes, é útil começar de forma ampla ​para entender as maiores tendências ​e as conclusões mais importantes ​e depois se aprofundar nos detalhes. ​Em segundo lugar, se você fizer ​uma descoberta ou encontrar uma visão ​interessante, cabe a você entender as implicações ​e tomar as decisões comerciais corretas.

\
​E, por fim, você sempre precisará verificar as descobertas ​para garantir sua precisão. ​Outra coisa a considerar é a privacidade de dados. ​O objetivo e a regra são simples: ​nunca insira dados confidenciais em uma ferramenta pública de IA ​e sempre consulte as políticas da sua empresa ​sobre o uso aceitável das ferramentas de IA. ​Agora, se você precisar trabalhar com dados confidenciais, ​você tem duas opções principais. ​Primeiro, veja se sua empresa tem uma ferramenta de IA de nível corporativo. ​A segunda opção é verificar as configurações ​da ferramenta pública que você está usando. ​Você pode desativar a coleta de dados ​ou ajustar seus controles de privacidade conforme necessário.

\
​Entender esses controles não é apenas uma questão de privacidade, ​mas também de oferecer a você o conhecimento e ​a confiança para analisar dados com IA. ​Ao final deste curso, ​você poderá usar o Gemini ​para descobrir os insights mais importantes ​escondidos em um oceano de dados. ​Então, vamos mergulhar.

## Crie um simulador de desempenho comercial para tomar decisões mais rápidas e orientadas por dados

Neste laboratório, Carol, da equipe da Gemini, mostrará como usar o Gemini Canvas para criar um simulador de desempenho empresarial que permite testar diferentes cenários e ver o impacto deles em tempo real. I’m a \[your role] at \[place of work e.g. an e-commerce business selling trousers]. My main goal is to \[goal, e.g. increase my profit this year]. Acting as a business advisor, analyze my \[type of data you upload to Gemini] and give me a list of the 3 most important changes I can make that would have the biggest impact on my goal.

Analise as sugestões de possíveis alterações fornecidas pelo Gemini. Você pode pedir a Gemini que lhe dê mais opções ou também pode iterar sobre elas. Você usará essas possíveis alterações para criar o simulador interativo na próxima etapa.
