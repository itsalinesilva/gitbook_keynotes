# Observabilidade

Eventos recomendados: - run_started / run_completed / run_failed; -
model_call; - retrieval_query / retrieval_results; - tool_call_started /
tool_call_completed / tool_call_failed; - handoff; - eval_completed; -
approval_requested / approval_granted / approval_denied; -
checkpoint_created / workflow_resumed.

Registre IDs, versões, latência, status, custo e referências de
artefatos. Não registre chain-of-thought privado, segredos ou conteúdo
sensível sem justificativa e autorização. Use redaction, controle de
acesso e retenção definida.
