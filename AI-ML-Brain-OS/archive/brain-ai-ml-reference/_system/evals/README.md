# Evaluation policy

Todo eval deve conter: - Objetivo e unidade avaliada; - Dataset/casos e
versão; - Critérios e rubricas explícitas; - Casos normais, limites e
adversariais; - Métrica e limiar; - Procedimento de execução; -
Resultados e limitações; - Owner e política de atualização.

Não use apenas um LLM-as-judge para avaliar tarefas de alto impacto.
Combine verificações determinísticas, referências humanas e múltiplos
sinais quando possível.
