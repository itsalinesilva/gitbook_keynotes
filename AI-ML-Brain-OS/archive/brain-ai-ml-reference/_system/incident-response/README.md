# Resposta a incidentes --- template

1.  Detectar e classificar severidade.
2.  Conter: revogar ferramentas/credenciais ou suspender workflow quando
    necessário.
3.  Preservar traces e evidências com acesso controlado.
4.  Avaliar escopo, impacto e dados afetados.
5.  Notificar responsáveis conforme política.
6.  Remediar e validar.
7.  Fazer análise de causa raiz.
8.  Criar ações preventivas e evals de regressão.
9.  Documentar timeline, decisões e aprendizados.
