# Catálogo de fontes

Campos mínimos: source_id, name, canonical_url, source_type, domains,
geographic_scope, source_role, authority_basis, known_biases,
collection_method, priority, owner_department, status, last_checked_at,
access_and_license.

Não pontue credibilidade como verdade universal; avalie a adequação da
fonte para a afirmação concreta.
