# Permissões

Defina permissões no runtime e no sistema operacional, não apenas em
texto de prompt.

Para cada papel, especifique: - Recursos legíveis; - Recursos
graváveis; - Ferramentas autorizadas; - Ações proibidas; - Limites de
custo e execução; - Aprovações necessárias; - Como auditar o
enforcement.

Nunca coloque segredos neste repositório.
