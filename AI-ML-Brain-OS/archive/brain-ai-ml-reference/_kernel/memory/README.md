# Política de memória

## Semântica

Conhecimento durável, referências, conceitos e fatos com proveniência.

## Episódica

Eventos, tarefas, decisões, incidentes e resultados.

## Procedural

Playbooks e skills versionadas.

## Estado de execução

Checkpoints e estado de workflows em andamento; não misturar com memória
semântica.

Cada memória deve ter owner, finalidade, validade, política de acesso,
retenção e mecanismo de correção/remoção.
