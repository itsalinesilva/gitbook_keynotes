# Brain OS --- Starter Repository

Este repositório é um scaffold de referência. Adapte antes de usar em
produção.

## Comece aqui

1.  Leia `00_MANIFESTO.md`.
2.  Leia `01_CONTEXT_MAP.md`.
3.  Revise `03_GLOBAL_POLICIES.md` e `_kernel/governance/`.
4.  Escolha um caso de uso piloto e crie evals antes de automatizar.
5.  Não conecte ferramentas de produção antes de definir permissões e
    aprovação.

O diretório `docs/` contém o manual de arquitetura. O scaffold não
inclui runtime, credenciais nem automações ativas.


## Expanded engineering blueprint

- `AI-ML-Brain-OS-Manual.md`: full manual with architecture, patterns, templates, tooling landscape and consolidated source bibliography.
- `docs/AI-ML-Brain-OS-Architecture-Expansion-v2.md`: expanded architecture section.
- `docs/tool-landscape.csv`: categorized official tool catalog for comparative evaluation.
- `docs/AI-ENGINEERING-CHECKLIST.md`: production release checklist.
- `docs/AI-SYSTEM-BRIEF-TEMPLATE.yaml`: system intake template.
- `docs/SOURCE-REGISTRY-TEMPLATE.yaml`: source provenance template.
- `docs/ARCHITECTURE-DECISION-MATRIX.md`: decision matrix to avoid premature complexity.
